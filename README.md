# Simon Says 🎮

Welcome to **Simon Says**, a fun and interactive memory game inspired by the classic “Simon Says” toy! This web-based game challenges users to recall and repeat sequences of colors as they grow longer and faster with each round.

## ✨ Features

- **Color Pattern Game**: Repeat the color sequence shown to continue to the next level.
- **Increasing Difficulty**: Each round adds a new color to the pattern, making it harder to remember.
- **Game Over Animation**: Visual feedback and a reset prompt when a mistake is made.
- **Sound Effects**: Engaging audio for each color and alert on errors.
- **Responsive UI**: Works smoothly on both desktop and mobile screens.

## 🛠️ Technologies Used

- **HTML**: Structure of the game elements.
- **CSS**: Styling for layout, colors, and animations.
- **JavaScript**: Core game logic including input handling, pattern generation, and state management.

## 💾 How to Play

1. Press any key (or tap on mobile) to start the game.
2. Observe the sequence of flashing colors and sounds.
3. Click the buttons in the exact order shown.
4. With each correct round, the pattern increases by one.
5. Make a mistake, and the game will end and prompt you to restart.
